# 07_lab06_multitask_lcd 构建与验证记录 (2026-09-01)

## 1. 实验内容
- 授课文档 4.10 节：多任务 + LCD (`lab06_multitask_lcd`)
- 使用 LiteOS-M 创建双并行任务：
  - 任务 1 `lab06_sample_task` (约 3000ms 周期)：慢速通过 I2C0 读取 SHT30 温湿度，更新 volatile 全局变量 `g_temp`/`g_humi`
  - 任务 2 `lab06_ui_task` (约 200ms 周期)：快速自增 `g_tick`，刷新屏幕 `Tick: %u`、温湿度数值，并监听 K3 边沿检测修改 `g_freeze`
- K3 冻结时：采样任务暂停更新温湿度数据（数值定格），但 UI 任务的 `Tick` 仍以 200ms 频率快速递增，充分验证两任务并行独立、互不阻塞！
