# 08_lab07_cabin_station 构建与验证记录 (2026-09-01)

## 1. 实验内容
- 授课文档 4.11 节：舱内环境监测站 (`lab07_cabin_station`)
- 四路传感器融合：
  - SHT30: 温度 `T` (℃)、湿度 `H` (%)
  - BH1750: 光照 `Lux`
  - MQ2: 气体浓度 `ppm`
- 双路告警联动：
  - 环境告警 (Lux < 50.0 或 Gas > 100.0ppm)：PA5 物理报警灯闪烁 + 电机转动
  - 热湿告警 (Temp > 35.0C 或 Humi > 80.0%)：RGB 白光常亮 + 电机转动
- K3 (`GPIO0_PC7`) 消警机制：
  - 短按 K3 立即关闭声光电机执行器，LCD 显示 `Status: ACK (MUTED)`
  - 当全部传感器数据回归正常区间后，系统自动退出消警状态 (`g_alarm_ack = false`)，重新进入 `ARMED` 自动监控状态。

## 3. 验收标准
1. 上电后 LCD 完整显示：
   - `TX-SMART-R Lab07 Cabin`
   - `T: xx.x C  H: xx.x %`
   - `Lux: xxx.x  Gas: xx.x ppm`
   - `Env: NORMAL`
   - `Thermal: NORMAL`
   - `Act: OFF (STANDBY)`
   - `Status: ARMED / RUNNING`
2. 串口周期输出完整传感器汇总行：`[sample] T=... H=... Lux=... Gas=...`；
3. 用手遮光（Lux < 50）或打火机微量气体（Gas > 100）：
   - PA5 报警灯开始闪烁，电机开启转动，LCD 显示 `Env: ALARM`
4. 用手捂热 SHT30（Temp > 35 或 Humi > 80）：
   - RGB 白光常亮，电机开启转动，LCD 显示 `Thermal: ALARM`
5. 短按 K3：
   - 告警灯、RGB、电机全部立即停止，LCD 显示 `Status: ACK (MUTED)`
   - 待环境完全恢复正常后，自动恢复 Armed 警戒状态。
