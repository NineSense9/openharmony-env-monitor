# 05_lab04_mq2_key_lcd 构建与验证记录 (2026-09-01)

## 1. 实验内容
- 授课文档 4.8 节：MQ2 气体 + 按键 + LCD (`lab04_mq2_key_lcd`)
- 使用 `DevIoInit` 与 `LzSaradcReadValue` 采集 MQ2 模拟分压（SARADC 通道 4，引脚 `GPIO0_PC4`）
- 依据标准气体公式计算浓度 `ppm = 613.9 * (rs / r0)^(-2.074)`
- LCD 屏幕实时更新 `Gas: xxx.x ppm`
- 短按 K3（`GPIO0_PC7`）执行 `mq2_ppm_calibration()` 重新校准基准 `r0`
- 串口周期打印 `Gas PPM = xxx.xx` 与校准详细参数

1. 上电后 LCD 显示:
   - `TX-SMART-R Lab04`
