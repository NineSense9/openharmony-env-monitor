# 06_lab05_sht30_key_lcd 构建与验证记录 (2026-09-01)

## 1. 实验内容
- 授课文档 4.9 节：SHT30 + 按键 + LCD (`lab05_sht30_key_lcd`)
- 使用 `I2cIoInit` 与 `LzI2cInit` 初始化 I2C0 通道（SCL=`GPIO0_PA1`, SDA=`GPIO0_PA0`）
- 周期向 SHT30（地址 `0x44`）发送读取指令 `0xE000` 并接收 6 字节温湿度原始值，通过 CRC8 校验后换算摄氏度与相对湿度
- LCD 屏幕实时更新 `Temp: xx.x C`、`Humi: xx.x %` 与 `Freeze: OFF / ON`
- 短按 K3（`GPIO0_PC7`）翻转 `freeze` 状态（冻结时屏幕数值定格，不更新传感器采样）
- 串口周期打印 `Temp = xx.x C, Humi = xx.x %` 与冻结状态切换

## 3. 验收标准
1. 上电后 LCD 显示:
   - `TX-SMART-R Lab05`
   - `LCD OK`
   - `OpenHarmony`
   - `Temp: xx.x C` (真实环境温度)
   - `Humi: xx.x %` (真实环境湿度)
   - `Freeze: OFF` (蓝色)
2. 串口每 500ms 输出当前真实温湿度；
3. 手捂传感器，温湿度数值发生明显上升变化；
4. 短按 K3 按键:
   - LCD 切换为 `Freeze: ON` (红色)，温湿度数据保持定格不再刷新
   - 再次短按 K3，LCD 切回 `Freeze: OFF` (蓝色)，数据恢复实时刷新。
