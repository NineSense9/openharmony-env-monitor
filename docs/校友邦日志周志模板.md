# 校友邦日志/周志模板(全组通用)

> 硬性要求:每人 **10 篇实习日志 + 2 篇周志**;不合格的要及时修改补交。
> 以下模板来自《生产实习流程梳理》第 9 节,写的时候替换方括号内容,别留空。

## 一、每日日志模板(每篇 200–400 字,当天写完)

```
日期:2026年X月X日(实习第X天)
今日阶段:北向阶段X / 南向阶段X / 整合答辩
【今日理论】今天上午老师讲解了……(2-3个知识点,用自己的话)
【今日实操】我在电脑上完成了……(具体产出:跑通的工程/界面/驱动/数据)
【遇到的问题】……问题:原因是……,通过……方式解决(或:已记录,明日继续排查)
【明日计划】明天计划完成……
【一句话心得】……
```

## 二、周志模板(共 2 篇)

### 第 1 篇(9/4 周五或周末写,覆盖 Day1–5)

```

目标完成情况:计划完成……,实际完成……,差距及原因……
技术收获:本周掌握了 ArkTS 页面开发 / ECharts 集成 / MQTT 通信 / 远程告警……
团队协作:本组X人,分工为……,协作方式为……,遇到的问题及处理……
下周计划:进入南向嵌入式开发(Docker编译环境、RK2206烧录、传感器驱动),担心的点是……,准备……
```

### 第 2 篇(9/11 周五写,覆盖 Day6–10 + 两周总结)

```
本周概述:完成南向开发与全链路联调、项目答辩。
目标完成情况:……

技术指标达成情况:采集误差__%、指令响应__ms、断网缓存__。
能力成长(对照工程认证目标挑3-4条):问题分析/工具使用/团队协作/沟通表达/项目管理……
答辩收获:演示与评审中暴露的不足、评委建议……
下一步目标:结合鸿蒙生态/物联网方向的学习或求职计划……
```

## 三、写作注意事项

1. 内容要"如实、具体":写自己真做过的事、真遇到的报错,别写空话;老师会核查。
2. 日志与周志、周志与总结报告之间内容要一致,不冲突。
3. 当天的截图/代码片段留好,写日志和最后总结报告都能复用。
4. 每篇写完让组内文档工程师交叉看一眼,降低"不合格退回"概率。
