## 3. 项目全景:太空空间站内部环境监测端云一体化系统

### 3.1 项目一句话【原文浓缩】

基于 **OpenHarmony 南北向全栈**,用鸿蒙南向开发板 + 空间站舱内环境传感器(气压、温度、湿度、风速),实现**舱内环境数据采集 → 本地显示 → 自动控制 → Wi-Fi 上云 → 鸿蒙 APP 远程监控 → 阈值告警**的全流程闭环。

### 3.2 系统五大链路【原文】

```
感知层 → 鸿蒙终端层 → 网络层 → 云端服务层 → 鸿蒙APP应用层
(传感器)  (RK2206)    (Wi-Fi)   (MQTT/存储)   (ArkTS/ArkUI)
```

### 3.3 六大核心功能模块【原文】

| # | 模块 | 功能点 |
|---|---|---|
| 1 | 多传感器数据采集 | 实时采集环境数据,滤波、误差校准 |
| 2 | 本地终端控制 | 自动阈值调控、声光告警、SPI 本地屏、低功耗休眠 |
| 3 | Wi-Fi-MQTT 双向通信 | 数据上传、远程指令下发、断网缓存恢复 |
| 4 | 鸿蒙 APP 可视化 | 实时数据卡片、历史曲线、异常标红、告警弹窗 |
| 5 | 远程管控 | 自定义告警阈值、远程启停执行设备、操作日志记录 |
| 6 | 工程拓展 | 设备功耗统计、实验数据导出、系统轻量化优化 |

### 3.4 量化技术指标【原文】

- 传感器采集误差 **< 3%**
- 远程指令响应 **< 500ms**
- 断网缓存支持 **24 小时**历史数据存储

## 10. 背景技术知识速查【背景知识】

> 均为通用常识,用于快速理解方案;具体型号、平台、版本以现场为准。

- **OpenHarmony**:开源鸿蒙;按设备 RAM 分轻量系统(Keystone/内核级)、小型系统、标准系统。RK2206 这类 MCU 板跑轻量/小型系统,APP 侧是标准系统。
- **南北向**:"北向"= 面向应用开发者(ArkTS/ArkUI APP);"南向"= 面向设备/驱动/内核(板卡、固件、HAL)。
- **ArkTS/ArkUI**:声明式 UI;常用装饰器 @Entry/@Component/@State/@Prop/@Link;页面路由 Router/Navigation。
- **MQTT**:发布/订阅;Broker/Client;核心参数 topic、QoS0/1/2、keepalive;断网容错常用离线缓存 + 重连补传(对应"24h 断网缓存"指标)。
- **I2C/SPI/GPIO**:I2C 两线多从机,常接温湿度(AHT20 类)、气压(BMP280 类)传感器;SPI 高速,常驱动 TFT 屏;GPIO 控蜂鸣器/LED(声光告警)与按键;风速传感器多为脉冲/模拟量输入。具体传感器型号【待确认】。
- **低功耗**:常见手段为休眠/停机模式 + 定时唤醒、外设时钟门控、降低上报频率;考核口径通常是电流均值。
- **数据校准**:多组传感器对照实验 → 误差统计(均值/方差/最大偏差)→ 线性校准/滤波(滑动均值、卡尔曼简化版)。
- **DevEco Studio**:鸿蒙应用 IDE;调试用模拟器或真机;南向烧录一般用板厂工具(如 Burner/擦写工具)或烧录器。

### 12.4 日常操作速查(怎么用)

**① 启动/关闭虚拟机**(三选一)
- 图形界面:打开 VirtualBox → 选中 "Ubuntu" → 点「启动」(首次启动建议用 GUI,能看见登录画面)。
- 命令行后台:`"C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" startvm Ubuntu`
- 关机:在 VM 里正常 shutdown;应急 `VBoxManage.exe controlvm Ubuntu poweroff`(相当于拔电,尽量别用)。
- **环境玩坏了**:VirtualBox → 选中 VM → 「快照」页 → 选中 `环境安装完毕`(或最干净的 `纯净镜像`)→ 「恢复」。

**② 网络说明**
- VM 上网走网卡1(NAT),无需配置。
- 从 Windows 连 VM(SSH/传文件)走网卡2 桥接:进 VM 后 `ip addr` 查 IP,Windows 侧 MobaXterm SSH 到该 IP。
- 若换网络环境后启动报 `Nonexistent host networking interface`,用 `VBoxManage list bridgedifs` 查当前网卡名,再 `modifyvm Ubuntu --bridgeadapter2 "<新网卡名>"`。

**③ MobaXterm 连板子串口(Day7-9)**
1. 板子插 USB → 设备管理器 →「端口(COM 和 LPT)」找新增 COMx(没有则是缺串口驱动,找老师要 CH340 类驱动)。
2. MobaXterm → Session → Serial → 端口选 COMx,Baudrate 115200(常用值,以现场为准),Flow control 选 None → OK。
3. 按板子复位键,窗口里滚出启动日志即连通。

**④ RKDevTool 烧录(Day7)**
1. 板子进入烧录模式(Loader/MaskROM,按键组合以现场教学为准);设备管理器出现 "Rockusb Device" 说明 12.2#3 装的驱动生效。

3. 烧录失败常见原因:没进烧录模式、驱动没装对、USB 线是纯充电线。

**⑤ Docker 编译(Day7,细节现场对齐)**
