# 2026年9月9日校友邦实习日志

## 提交标题

Web数字孪生大屏全景重构：天和核心舱立体透视、板卡仿真与自适应等比缩放引擎

## 提交正文

日期：2026年9月9日（第8天）

阶段：北向 Web 数字孪生大屏全景重构与跨分辨率工业级自适应引擎研发

【理论】
深入学习工业级 DataV 智慧大屏的前端响应式架构体系；掌握 CSS3 Transform 矩阵缩放原理（以 1920x1080 为基准等比缩放并居中）与视口适配算法；理解复杂矢量图形分层渲染优化与流体粒子动态力学仿真的性能调优技巧。

【今日实操】
1. **天和核心舱宽屏立体透视大屏（CabinTwin.tsx）全面重构**：
   - 优化核心舱 920px 黄金宽屏比例，绘制高精细矢量外壳、法兰对接环与多孔排气栅格，去除非标文字重叠与视觉杂乱元素；
   - 完美联动实时遥测温湿度、光照、烟雾与 MPU6050 空间姿态角，实现微气候与舱体环境状态的动态视觉渲染；
2. **小凌派-RK2206 实物板卡高保真数字孪生开发**：
   - 矢量精准复刻深蓝太空沉金 PCB、RK2206 主控芯片、320x240 LCD 实时镜面映射显示，以及无刷风机叶轮随实物 PWM 档位动态旋转物理特效；
3. **AirflowCanvas 空间站核心舱流体粒子动力学动态气流场仿真**：
   - 基于 Canvas 研发流体粒子动力学气流场，流速与粒子流向与风机 PWM 档位及温度梯度实时联动，搭配 ECharts 5 动态时序走势；
4. **DataV 级跨设备多分辨率自适应等比缩放引擎研发**：
   - 研发基于容器缩放比率 scale = Math.min(w/1920, h/1080) 的自适应引擎，完美兼容笔记本小屏幕（1080p、1366x768）与展厅 2K/4K 巨幕大屏，杜绝元素错位与排版拥挤；
   - 设计中国空间站天和核心舱专属航天矢量 Favicon 网页图标。

【遇到的问题】
在从外接 4K 大显示器切换回笔记本内置屏幕时，大屏中段排版出现局部压缩与高度溢出。通过使用父级视口监听器动态计算等比缩放比率，结合 transform: scale(...) 与 transform-origin: center top 彻底解决跨分辨率错位。

【明日计划】
全面升级鸿蒙原生 ArkTS APP，重构 4-Tab 航电工作台与原生 Canvas 动态环形饼图。
