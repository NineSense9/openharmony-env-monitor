# 2026年9月2日校友邦实习日志

## 提交标题

云端微服务架构优化、时序数据持久化与指令队列ACK闭环机制

## 提交正文

日期：2026年9月2日（第3天）

阶段：云端微服务与高可用数据通信架构开发

【理论】
深入学习 FastAPI 异步框架的高并发处理机制，掌握基于 SQLAlchemy 的异步 ORM 映射与 SQLite 时序数据写入性能调优；理解物联网中指令下发与 ACK 应答确认机制的设计规范；学习心跳失锁检测与状态机超时回滚算法。

【今日实操】
1. **云端微服务接口重构与调优**：
   - 完善百度云 BCC 上的 FastAPI 遥测服务，重构 `/api/telemetry` 上报端点，增加数据校验与批次写入缓冲区；
   - 优化 `/api/telemetry/latest` 与 `/api/telemetry/history` 端点，支持毫秒级时间戳范围查询与下采样聚合算法；
2. **指令下发与 ACK 闭环队列设计**：
   - 设计基于内存+持久化的双级指令队列，支持 Web/APP 端向 RK2206 下发风机、告警控制指令；
   - 实现设备端指令轮询获取与执行后 ACK 状态回传机制，杜绝指令丢失与乱序；
3. **失锁心跳容错检测**：
   - 实现 6 秒超时心跳判定定时器，当开发板网络中断时自动将云端状态标记为 `[CACHED]` 缓存模式，并向前端推送离线预警信号。

【遇到的问题】
高频 500ms 遥测写入导致 SQLite 短暂锁等待，通过将数据库切换为 WAL 模式并配置连接池 busy_timeout 为 5000ms 解决。

【明日计划】
深入鸿蒙原生 ArkTS 应用的 HUD 组件化封装与 Canvas 示波器走势图硬件加速优化。

【一句话心得】
稳定的云端中枢与可靠的 ACK 确认机制是保证端云一体化物联网系统实时闭环的核心底座。
