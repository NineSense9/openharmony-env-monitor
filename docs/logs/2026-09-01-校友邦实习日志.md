# 2026年9月1日校友邦实习日志

## 提交标题

太空空间站端云一体化环境监测系统全栈研发与联调

## 提交正文

日期：2026年9月1日（第2天）

阶段：南北向全栈开发、云端微服务部署与 Web/ArkTS 双端可视化控制台实现

【理论】
深入学习 OpenHarmony 3.0 LTS 驱动架构与 LiteOS-M 多任务调度，掌握 I2C/SARADC 传感器采样、lwIP 网络协议栈与 Wi-Fi 通信机制；学习 FastAPI 云端微服务架构与异步数据流；掌握 React 18 现代 Web 工程化与 DevEco Studio 6.1 下 ArkTS Stage 模型的声明式 UI 开发。

【今日实操】
1. **南向设备端（RK2206）嵌入式开发与实验落地**：
   - 调试完成 SPI TFT-LCD 屏幕驱动，实现 180° 正向对齐与 60 个中文字模库防残影刷新；
   - 优化 K3 按键为最高优先级（Prio 3）硬件级边沿检测与防抖，实现即按即响；
   - 完成 SHT30（温湿度）、BH1750（光照）、MQ-2（烟雾）多传感器数据采集、校准与多任务并发调度；
   - 调通 Wi-Fi 联网上云，实现 500ms 极速遥测上报与 200ms 远程指令轮询，手机停机后自动解除远程覆盖恢复正常监测。
2. **云端微服务（百度云 BCC）**：
   - 在 180.76.137.117:8000 部署上线 FastAPI + SQLite 遥测微服务，提供遥测入库、历史查询与失锁心跳检测接口。
3. **Web 北向太空数字孪生大屏**：
   - 基于 React 18 + TS + ECharts 5 研发航电 HUD 质感数字孪生大屏，支持动态气流粒子流体仿真与 <240ms 极速双向物理联动。
4. **鸿蒙原生 ArkTS 掌上测控终端 APP**：
   - 适配 DevEco Studio 6.1 NEXT 规范，通过 `hvigor assembleHap` 全量编译打包生成 HAP；
   - 践行航电工程级设计规范，彻底剔除 Emoji，全套采用自研 11 组高精度纯矢量 SVG 图标；
   - 实现 360° 激光雷达冷启动自检开屏画面（`SplashScreen`）、60fps 动态旋转涡轮风机动画与 Canvas 双色面积渐变示波走势；
   - 实现会话级 6 位 PIN 码（123456）免密授权记忆与自适应防横向溢出布局。

【遇到的问题】
1. **DevEco 路径与规范兼容**：工程路径含中文报错，通过建立独立规范工程与标准 build-profile 解决；
2. **控制台窄屏溢出**：重构自适应 Flex 布局与 `RTT<240ms` 芯片解决；
3. **固件停机状态未清零**：在停止电机逻辑中主动清零 `g_remote_override`，使板端瞬间恢复正常监测。

【明日/后续计划】完成生产实习总结报告、答辩 PPT 制作与全系统软硬件实物演示演练。

【一句话心得】贯通了感知层、云端、Web大屏到鸿蒙原生APP的全链路闭环，达成端到端毫秒级实时双向联动的端云一体化系统。
