# 2026年9月1日校友邦实习日志（第2篇）

## 提交标题

OpenHarmony南向硬件综合站全链路验收与百度云端联调成功

## 提交正文

日期：2026年9月1日（第2天上午）

阶段：南向开发与端云通信

【理论】深入学习 OpenHarmony 多任务调度（LOS_Task）、互斥同步机制与 SPI/I2C/ADC 传感器驱动框架。掌握 lwIP 协议栈下的 TCP Socket 编程，理解 JSON 结构化遥测上报与 HTTP RESTful API 交互契约。

【今日实操】
1. 依次完成 Lab01~Lab08 基础外设实验：LCD 驱动、按键中断、三色 LED、MQ2 烟雾传感器、SHT30 温湿度、多任务并发调度与 Wi-Fi 联网；
2. 完成综合上云实验 Lab09：实现开发板开机自动连接 Wi-Fi，2.4 寸 LCD 双色屏实时渲染环境指标；
3. 开发板通过 TCP Socket 直连百度云 BCC 服务器，每 3 秒稳定上报四路传感器遥测数据；
4. 实现了云端控制指令下发闭环：云端下发电机启停指令，开发板在 2~3 秒内精准响应驱动电机旋转，并向云端返回 `executed on rk2206` ACK 回执。

【遇到的问题】
1. 遥测上传时出现 `"value": null` 字段导致解析误判，通过优化 JSON 序列化与异常字段清洗解决；
2. LCD 刷新字符长度不一时出现残余括号字符重影，通过引入定长空格格式化清洗机制彻底修复。

【明日/后续计划】开展北向数字孪生可视化大屏与移动端 APP 研发，进一步压缩端云通信延迟。

【一句话心得】南向硬件从单个外设驱动到综合上云实物闭环一次性全部调通，建立了端到端完整的物联网系统工程视野。
