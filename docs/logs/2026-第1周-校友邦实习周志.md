# 2026年生产实习第1周周志

## 提交标题

生产实习第1周总结：南向驱动攻坚、端云协议构建与双端可视化系统落地

## 提交正文

实习时间：2026年8月31日 – 2026年9月4日（第1周）
指导单位：软通动力 / 沈阳航空航天大学

### 一、 本周主要工作与进度总结
本周完成了中国空间站内部环境监测端云一体化系统的**全技术栈框架搭建与核心功能闭环**：
1. **南向嵌入式层（RK2206）**：搭建 Ubuntu 编译链与 RKDevTool 烧录环境，独立完成 SHT30、BH1750、MQ-2 传感器驱动与 ST7789V2 SPI 液晶屏驱动开发，实现 LiteOS-M 多任务并发采集；
2. **网络与云端中枢层**：调通 Wi-Fi Station 模式与 lwIP 协议栈，在百度云 BCC 部署 FastAPI 微服务，实现时序遥测存储、指令 ACK 闭环与 6s 心跳失锁快照；
3. **北向呈现双端**：
   - 研发鸿蒙原生 ArkTS APP，构建 11 组纯矢量 HUD、360° 激光雷达开屏自检与 Canvas 示波器走势；
   - 研发 Web React 18 数字孪生大屏，完成动态气流粒子流体仿真与多维态势看板。

### 二、 核心攻关与技术收获
1. 深入掌握了 OpenHarmony 3.0 LTS 驱动框架及嵌入式 RTOS 多任务并发同步机制；
2. 攻克了端到端跨网络层指令双向传输协议设计，打通了“下位机 <-> 云端 <-> 双端”完整链路；
3. 掌握了 DevEco Studio 6.1 下 ArkTS 纯矢量工业级 UI/UX 设计规范。

### 三、 遇到的主要困难与解决措施
1. **SQLite 写入锁竞争**：通过开启 WAL 模式及短事务设计彻底消除锁阻塞；
2. **Canvas 渲染内存泄漏**：在流体粒子仿真中引入对象池机制，使大屏连续运行内存保持平稳。

### 四、 下周工作规划与学习目标
1. 深入优化嵌入式底层状态机逻辑，解决停机状态自动复位与 LCD 点阵汉字字模补齐；
2. 进行全链路双向时延基准测试与极限压力测试，确保端到端响应时延稳定在 <240ms；
3. 完成全套生产实习技术文档、答辩 PPT 制作与结项汇报准备。

### 五、 本周实习体会
通过第一周高强度的软硬件全栈实战，我不仅打通了从底层硬件驱动到顶层鸿蒙应用的完整数据流，更体会到了工程化思维在复杂物联网系统中的核心价值。
