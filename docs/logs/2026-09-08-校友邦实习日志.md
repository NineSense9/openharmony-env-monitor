# 2026年9月8日校友邦实习日志

## 提交标题

多外设执行器联动与安全冗余体系：PWM五档风机调速、WDT看门狗与远程软重启

## 提交正文

日期：2026年9月8日（第7天）

阶段：执行器精准调控、硬件看门狗保活与系统容灾冗余体系研发

【理论】
深入学习脉冲宽度调制（PWM）工作频率、占空比与电机无级调速原理；掌握嵌入式硬件看门狗定时器（WDT）在死循环与任务阻塞时的硬件复位防死锁机制；研究工业级物联网远程维护协议、安全 PIN 码鉴权认证以及 I2C 总线拓扑动态探测扫描原理。

【今日实操】
1. **PWM 硬件级多档位智能换气风机调速研发**：
   - 基于 RK2206 定时器 PWM 通道，编写排风换气风机五档精细化调速控制模块；
   - 实现 0 档停机（0%）、1 档微风换气（30%）、2 档常规巡检（65%）、3 档强力排烟（100%）及 AUTO 模式（依据舱内温湿度与烟雾浓度自适应平滑调速）；
2. **RK2206 底层硬件看门狗 WDT 保活与防死锁设计**：
   - 初始化 RK2206 硬件看门狗，配置 20 秒超时复位窗口；
   - 在 LiteOS-M 主任务循环与网络通信任务中引入周期性喂狗保活逻辑，当系统发生不可恢复死锁或任务挂死时触发硬件自动复位重启；
3. **系统远程安全软重启与 PIN 码鉴权认证**：
   - 设计端云协同远程控制协议，支持 target="system", action="reboot" 指令；
   - 引入 6 位安全 PIN 码（123456）授权确认机制，防止误操作与越权控制；
4. **I2C0 总线在线从机动态扫描机制实现**：
   - 编写 I2C0 总线全地址空间（0x03 ~ 0x77）扫描轮询函数，实时探测并动态识别 SHT30、BH1750、MPU6050 等传感器挂载状态。

【遇到的问题】
风机在由低速急加速至 100% 满转速瞬间，电机启动冲击电流造成局部供电电压微降，触发 ADC 瞬间误判。通过在驱动层引入 PWM 占空比阶梯式平滑爬升算法（S-Curve），消除了电流浪涌对系统总线的冲击。
