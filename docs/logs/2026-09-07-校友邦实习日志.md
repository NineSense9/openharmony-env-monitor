# 2026年9月7日校友邦实习日志

## 提交标题

南向驱动深度扩展：SARADC5四按键矩阵、MPU6050姿态导航与微重力平滑回退研发

## 提交正文

日期：2026年9月7日（第6天）

阶段：南向嵌入式驱动深度扩展与空间站座舱 HUD 界面重构

【理论】
深入学习电阻分压网络与单通道模拟数字转换（ADC）多按键电压判决原理；掌握 I2C 总线协议时序与 MPU6050 六轴运动处理传感器工作原理，理解基于重力加速度矢量的俯仰角（Pitch）与横滚角（Roll）姿态解算算法；研究微重力环境下空间站姿态传感器信号滤波与自适应平滑回退数学模型。

【今日实操】
1. **SARADC5 (GPIO0_PC5) 四按键分压电阻网络矩阵研发**：
   - 基于小凌派-RK2206 开发板 SARADC5 单引脚电阻分压网络，编写多按键电压区间采样与判决算法；
   - 精确划分电压阈值窗口，实现 K3 (应急报警/消警)、K4 (风机手动加档)、K5 (模式切换/照明)、K6 (网络配网/系统自检) 4 组物理按键的可靠识别，并引入 20ms 软件消抖机制；
2. **I2C0 挂载 MPU6050 姿态传感器与几何姿态解算**：
   - 编写 I2C0 总线驱动程序，成功挂载 MPU6050（设备地址 0x68），实现三轴加速度计与三轴陀螺仪原始数据的高速读取；
   - 运用三角几何公式完成空间站实时俯仰角（Pitch）与横滚角（Roll）的姿态角解算；
   - 设计并实现微重力轨道姿态自平滑回退数学模型，在传感器物理离线或微重力扰动时自动保持平稳航向数据；
3. **ST7789V2 2.4寸 SPI 液晶屏 320x240 HUD 航电座舱重构**：
   - 重构下位机屏幕显示布局为空间站 HUD 驾驶舱航电风格；
   - 实现微型条形进度走势图、姿态地平仪动态水平线渲染，并在屏幕底部增加 K3~K6 即时反色按键胶囊视觉反馈。

【遇到的问题】
SARADC 单线采集多按键时，按键机械动作瞬态边缘电压易跳变引起临近按键误识别。通过划分合理的电压容差窗口（±150mV），并在判定初值后增加 20ms 延时二次校验，彻底杜绝了按键误触与连击。

【明日计划】
研发 PWM 硬件级多档位智能换气风机驱动，构建 RK2206 硬件看门狗 WDT 防死锁安全机制与远程系统软重启功能。

【一句话心得】
利用单 ADC 引脚巧妙实现四键矩阵并融合空间姿态解算，不仅极大节约了微控制器的 GPIO 资源，更赋予了下位机浓厚的航天工程质感。
