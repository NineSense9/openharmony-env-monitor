阶段：Web 视口全分辨率自适应、ArkTS 环控动态饼图实现、UTC 极速对时与 PA5 舱内照明远程控制

【理论】
深入研究现代工业级数据可视化大屏（DataV）在跨分辨率、多显示设备（笔记本 1080P / 外接 2K / 4K 大屏）下的等比无损缩放引擎原理；研究非闭环微重力环境控制与生命保障系统（ECLSS）气体平衡、温湿度调节与环境能耗占比模型；深入理解嵌入式 GPIO 多功能复用设计规范与 RESTful 指令下发在端云双向闭环中的时序控制。

【今日实操】
1. **Web 数字孪生监控大屏多分辨率自适应缩放引擎**：
   - 针对不同显示器（外接大屏与笔记本高分屏）分辨率切换导致的视口排版挤压问题，引入 DataV 级动态自适应缩放算法；
   - 监听窗口 resize 事件，基准设计稿为 1920×1080，动态计算宽高等比缩放比率（scale = Math.min(w/1920, h/1080)）并居中渲染，彻底杜绝元素错位与文字截断；
   - 提取空间站矢量徽标生成透明 Favicon 图标（favicon.svg），完善 Web 端浏览器标签页工程细节。

2. **鸿蒙原生 ArkTS 环控能耗与环境占比动态环形饼图（AtmospherePieChart.ets）**：
   - 针对导师与评委对多维图表（折线图+饼图/环形图）的答辩展示要求，在 ArkTS 掌上端 Tab 0（空间监测）新增纯原生 Canvas 矢量环控饼图；
   - 严谨杜绝纯静态“画皮假数据”，接入小凌派底层上报的真实遥测数据（光照/辐射热负荷、温湿度平衡、风机循环能耗与生保基准负载），动态计算占比角度与百分比；
   - 针对空间站室内温湿度微弱变化，引入高灵敏度动态放大与平滑算法，确保微小环境变动（如吹气、手捂、遮光）即时在饼图占比中呈现清晰动画与灵敏反馈；
   - 支持点击交互在“环控能耗占比”与“气体环境比例”之间自由切换。

3. **UTC 时区与硬件在线状态识别调优（修复 CACHED 误判）**：
   - 深入排查移动端在网络连通下偶发显示 CACHED（缓存状态）的根本原因：后端 SQLite 数据库存储的为纯 UTC 时间，前端与移动端本地时区偏差导致秒级时间差判定超时；
   - 在 FastAPI 云端序列化中明确附加 +00:00 ISO 8601 时区标识，ArkTS 端针对时间字符串智能补齐 Z 格式进行严格 UTC 解析；
   - 修复后只要硬件持续上报（<6s），移动端右上角状态灯即刻稳固点亮 ● LIVE LINK (在线实况)。

4. **舱内照明与 PA5 警示灯远程双向控制全链路打通**：
   - **硬件引脚复用与协议定义**：选用底板用户指示灯 D1（GPIO0_PA5，TX_GPIO_ALARM_LIGHT），云端扩展 target="led", action="on"/"off" 语义；
   - **Web 控制面板新增照明模块**：在 ControlPanel.tsx 中增加“舱内照明与 PA5 警示灯 (GPIO0_PA5)”独立操作卡片，支持 PIN 码授权、点亮（ON）与熄灭（OFF）以及状态显示；
   - **数字孪生板卡双向联动**：当照明开启或警报触发时，BoardDigitalTwin.tsx 上的 PA5 D1 红色指示灯同步点亮呼吸闪烁动画，舱内照明环境变亮；
   - **ArkTS 移动端同步集成**：在 ControlSection.ets 机构控制页中增加独立照明控制按钮与状态徽标，StationViewModel.ets 实现 sendLedCommand 与遥测 alarm_on 状态自动绑定；
   - **编译部署与全链路验证**：Web 编译更新并同步热部署至百度云 BCC 服务器（180.76.137.117:8000），ArkTS 代码同步至 D:\openharmony_app 并使用 Hvigor 执行无错增量编译（BUILD SUCCESSFUL in 3.7s）。

【遇到的问题】
1. **跨分辨率排版适配溢出**：早期采用 flex 简单自适应在 100% 缩放笔记本屏幕上因高度不足导致内容超出视口，改用 DataV 经典的统一基准坐标系 + CSS Transform 矩阵缩放方案后彻底解决；
2. **传感器静态读数下饼图占比变化不明显**：室内常态下温湿度与光照通常较为平稳，常规比例尺变化幅度极小；设计了基准平衡模型与高灵敏度波动放大算法，使手捂传感器或光照遮挡等测试动作能产生生动明显的饼图比例伸缩；
3. **时区差导致在线状态识别偏差**：Python datetime.utcnow() 写入 SQLite 时丢失时区信息，序列化输出时显式补充 UTC 时区偏移量解决。
