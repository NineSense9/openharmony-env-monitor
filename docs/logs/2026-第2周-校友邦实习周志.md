# 2026年生产实习第2周周志

生产实习第2周总结：硬件深度扩展、端云双向闭环、多端孪生重构与结项圆满完成

## 提交正文

实习时间：2026年9月7日 – 2026年9月11日（第2周）
指导单位：软通动力 / 沈阳航空航天大学

### 一、 本周主要工作与进度总结
本周围绕中国空间站内部环境监测端云一体化系统展开了**硬件驱动深度扩展、安全冗余体系构建、北向双端界面全面重构与端云双向闭环落地**：
1. **南向感知与控制深度扩展（RK2206）**：
   - 研发 SARADC5 单引脚四按键（K3/K4/K5/K6）分压电阻网络识别与 20ms 硬件消抖算法；
   - 挂载 MPU6050 姿态传感器并完成俯仰角与横滚角几何解算，实现微重力轨道姿态平滑回退模型；
   - 研发 PWM 硬件级五档智能换气风机（0档停机/1档30%/2档65%/3档100%/AUTO自适应调速）；
   - 初始化 RK2206 硬件看门狗 WDT（20s）周期保活机制，实现抗死锁硬件复位与远程安全软重启；
   - 打通 GPIO0_PA5 舱内照明指示灯远程控制，并在 Ubuntu 编译链中编译构建出 v5.2 生产固件 Firmware.img；
2. **北向 Web 数字孪生大屏全景重构**：
   - 重构天和核心舱宽屏立体透视大屏（CabinTwin），绘制精密法兰对接环与多孔排气栅格；
   - 研发小凌派实物板卡高保真数字孪生（深蓝沉金 PCB、芯片、LCD 镜面映射、风机动态旋转）；
   - 研发 AirflowCanvas 流体动力学气流场仿真算法与 DataV 级跨分辨率等比自适应缩放引擎（scale = Math.min(w/1920, h/1080)），完美兼容笔记本屏与 4K 大屏；
3. **鸿蒙原生 ArkTS 掌上测控终端全面重构**：
   - 升级为 Navigation 4-Tab 航电工作台（空间监测/机构控制/硬件孪生/时序日志）；
   - 研发天和核心舱掌上透视卡片（CabinTwinCard）与原生 Canvas 动态环形饼图（AtmospherePieChart），灵敏呈现真实遥测微变；
   - 制作 512x512 高清矢量图标，消除手机窄屏按键文字截断；
4. **端云全链路双向闭环与集成验收**：
   - 修复 UTC 时间戳解析故障，彻底根除断网误判与按钮自动弹回，端到端控制响应时延稳定在 **< 240ms**；
   - 圆满完成软硬件综合实操集成测试、技术文档归档与结项答辩现场实物联动演示。

### 二、 核心攻关与技术收获
1. **紧凑硬件资源极限利用**：通过单 ADC 引脚实现 4 按键电压矩阵判决，结合 I2C0 动态拓扑扫描与 MPU6050 姿态解算，极大拓宽了下位机的物理感知维度；
2. **工业级嵌入式安全冗余**：将硬件看门狗 WDT 周期保活、阶梯调速防浪涌冲击与安全 PIN 码鉴权有机结合，构筑了高可用的底层运行底座；
3. **端云双向实时控制闭环**：不仅实现了下位机数据高速上报，更打通了云端指令下发、状态机记忆与硬件引脚电平驱动的毫秒级双向全闭环；
4. **现代跨端工程与高保真呈现**：掌握了 React 18 Canvas 流体粒子仿真、DataV 等比缩放适配，以及 ArkTS 声明式 UI 和原生 Canvas 矢量图表设计。

### 三、 遇到的主要困难与解决措施
1. **远程照明按钮弹回且硬件未响应**：经全链路抓包排查发现云端接口未持久化状态且下位机未解析相应分支，通过增加云端状态缓存与固件 PA5 电平驱动彻底解决；
2. **时间戳解析异常导致误判断网**：前端将带时区的时间戳字符串错误拼接 'Z' 导致解析出 NaN，通过标准化 ISO-8601 解析逻辑彻底恢复稳定遥测流；
3. **跨分辨率大屏排版错位**：通过引入以 1920x1080 为基准的等比缩放矩阵（CSS transform-origin），实现笔记本至 4K 大屏的无缝居中适配。

### 四、 生产实习总评与综合收获
本次为期两周的生产实习，紧密围绕国产自主可控的 OpenHarmony 3.0 LTS 开源生态展开。在指导教师和工程团队的带领下，我独立打通了“小凌派-RK2206 南向嵌入式驱动开发 -> 百度云微服务遥测中枢 -> Web 工业级数字孪生大屏 -> 鸿蒙原生 ArkTS 掌上终端”全技术栈闭环。从底层的 C 语言中断、ADC 采样、PWM 调速与 WDT 保活，到云端的异步架构与数据中枢，再到北向的双端高保真交互与流体粒子仿真，整套系统在结项答辩中表现出色、稳定可靠。这不仅极大地深化了我对嵌入式操作系统与分布式物联网架构的理解，更培养了我严谨求实的工程素养与解决复杂全栈问题的综合实战能力。
