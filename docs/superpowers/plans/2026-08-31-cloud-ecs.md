# Cloud ECS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the course cloud service for telemetry, alerts, and commands on the dedicated BCC instance with SQLite persistence.

**Architecture:** A single FastAPI app serves `/health` and the course APIs, backed by SQLAlchemy models over a local SQLite database. The app runs under `uvicorn` in a dedicated `envmonitor` system user account, with a `systemd` unit to keep it alive and a separate data directory so it does not interfere with existing server services.

**Tech Stack:** Python 3.10, FastAPI, Uvicorn, SQLAlchemy 2.x, SQLite, Pytest, systemd, Bash.
