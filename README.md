## 🌟 核心功能与硬件深度扩展

基于官方 **Lockzhiner RK2206 OpenHarmony 3.0 LTS 样例库** 与 **小凌派硬件原理图**，本项目完成了多项重大硬件级特性与全链路功能升级：

### 1. 🖲️ SARADC5 (GPIO0_PC5) 四按键分压电阻网络矩阵 (K3/K4/K5/K6)
* **原理图电路拓扑**：底板通过 4 组阶梯上拉分压电阻将按键信号汇聚至 `USER_KEY_ADC`（`SARADC5`，`GPIO0_PC5`），实现单 ADC 引脚精确判决 4 组物理按键；
* **电压分压基准判决窗口**：
  $$\text{ADC Voltage} = 3.3\text{V} \times \frac{R_{\text{down}}}{R_{\text{up}} + R_{\text{down}}}$$
  * **K3 按键**：$0.00\text{V} \sim 0.30\text{V}$（标称 $0.01\text{V}$） $\rightarrow$ **应急消警静音 / 恢复正常模式**；
  * **K4 按键**：$0.35\text{V} \sim 0.75\text{V}$（标称 $0.55\text{V}$） $\rightarrow$ **风机档位循环切换（0:停机 $\rightarrow$ 1:30% $\rightarrow$ 2:65% $\rightarrow$ 3:100% $\rightarrow$ 4:AUTO）**；
  * **K5 按键**：$0.80\text{V} \sim 1.30\text{V}$（标称 $1.00\text{V}$） $\rightarrow$ **声光告警硬件自检模式（Toggle Test）**；
  * **K6 按键**：$1.40\text{V} \sim 2.00\text{V}$（标称 $1.65\text{V}$） $\rightarrow$ **触发 I2C0 总线实时重扫与在线拓扑识别**；
  * **空闲常态**：$> 2.80\text{V}$（标称 $3.30\text{V}$）。
* **双模向下兼容**：同时保持对数字引脚 `GPIO0_PC7` 的中断与电平扫描，确保单线接法与多键接法 100% 兼容。

### 2. 🧭 MPU6050 空间站姿态导航与微重力回退仿真
* **I2C 物理挂载**：在 `I2C0` 总线（`GPIO0_PA0/PA1`）寻址 `0x68`，通过寄存器 `0x75 (WHO_AM_I)` 自动握手；
* **姿态解算算法**：读取三轴加速度原始数据计算空间站俯仰角（Pitch）与横滚角（Roll）：
  $$\text{Pitch} = \arctan\left(\frac{a_y}{\sqrt{a_x^2 + a_z^2}}\right) \times \frac{180^\circ}{\pi}, \quad \text{Roll} = \arctan\left(\frac{-a_x}{a_z}\right) \times \frac{180^\circ}{\pi}$$
* **微重力轨道自平滑回退算法**：若底板未外接 MPU6050 芯片，底层自动无缝切换为内置空间站微重力姿态数学模型，模拟失重漂移与姿态扰动，确保上层应用与云端永不断流。

### 3. 🌀 PWM 硬件级多档位智能换气风机（0/1/2/3/AUTO）
* **五档变速控制**：
  * **0 档（停机）**：占空比 $0\%$，电机断电停转；
  * **1 档（弱风）**：占空比 $30\%$，超静音微风维持舱内气压；
  * **2 档（中风）**：占空比 $65\%$，标准舱内对流通风；
  * **3 档（强风）**：占空比 $100\%$，应急超速排烟排毒（6000 RPM）；
  * **4 档（AUTO）**：智能自适应温控算法，根据 SHT30 温度自动分级加速。
* **物理引脚并联驱动**：`GPIO1_PD0`（主引脚）与 `GPIO0_PC6`、`GPIO0_PA2` 协同驱动。

### 4. 🔊 航天和弦开机音效与双频警报声笛
* **双音和弦开机 Chime**：设备冷启动自检时，由蜂鸣器播放 1500Hz 与 2200Hz 和弦音效（各 80ms/100ms），提供高质感听觉反馈；
* **空间站双频警报 Siren**：警报触发期间，交替以 1000Hz 与 2000Hz 节奏啸叫，配合 PA5 红色高亮 LED 闪烁。

### 5. 🐕 硬件看门狗 WDT（20s 保活防死锁）
* 采用 RK2206 底层硬件看门狗（`LzWatchdogInit(20)`），在核心测控主循环中执行 `LzWatchdogKeepAlive()`；若系统任务因异常挂起超过 20 秒，硬件看门狗将自动触发芯片复位，保障空间站极端工况下的永不死机。

### 6. 🔄 远程系统安全软重启（RebootDevice）
* 云端与移动端可通过 `target="system", action="reboot"` 指令，经 6 位安全 PIN 码（`123456`）二次确认后，安全关闭电机和声光外设，调用系统复位接口重启开发板。

### 7. 🔍 I2C0 总线拓扑自动探测扫描
* 开机与按下 K6 键时，自动扫描 `0x03 ~ 0x77` 地址空间，动态报告在线从机列表（`SHT30:0x44`、`BH1750:0x23`、`MPU6050:0x68`），实时同步至屏显与云端。

```json
  "accel_z": 0.98,
  "pitch": 2.4,
  "roll": -1.8,

  "wdt_alive": true,
  "i2c_devices": "SHT30,BH1750,MPU6050",
  "last_key": "K4"

```

### 2. 远程下行控制指令集（POST `/api/command`）

| 控制目标 (`target`) | 控制动作 (`action`) | 触发说明与动作行为 |
|---|---|---|
| `fan` / `motor` | `speed_0` / `off` | 关闭风扇，占空比设为 0% |
| `fan` / `motor` | `speed_1` | 切换至 1 档（低速 30% PWM） |
| `fan` / `motor` | `speed_2` | 切换至 2 档（中速 65% PWM） |
| `fan` / `motor` | `speed_3` / `on` | 切换至 3 档（全速 100% PWM，6000 RPM） |
| `fan` / `motor` | `auto` | 切换至 AUTO 智能温控档（动态根据 SHT30 温度调节） |
| `alarm` | `ack` | 应急消警并进入静音锁存模式，解除声光蜂鸣 |
| `system` | `reboot` | 远程软重启开发板，调用底层 `RebootDevice(0)` |
